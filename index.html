TRANSITIONとは？

CSSの状態が変化するとき、その変化をなめらかにする。

(1)ボタン

ボタンにマウスを乗せて、実際に動きを体験しよう。

  • 色が変わる

    background-color

    詳しくはこちら→ 
      .iro {
 transition: background-color 0.25s ease;
 }

 .iro:hover {
 background-color: #FFC72C;
 }

  • 背景が伸びる

    ::before+scalex

    詳しくはこちら→
      .nobiru {
 position: relative;
 overflow: hidden;
 /* はみ出した背景を隠す */
z-index: 0;
}

.nobiru::before {
content: "";
position: absolute;
inset: 0;
/* top/right/bottom/left: 0 のまとめ書き */
z-index: -1;
background-color: #FFC72C;
transform: scaleX(0);
/* 横幅0の状態からスタート */
transform-origin: left;
/* 左端を軸に伸ばす */
transition: transform 0.3s ease;
}

.nobiru:hover::before {
transform: scaleX(1);
}

  • 浮かび上がる

    translateY+box-shadow

    詳しくはこちら→
     .ukabu {
box-shadow: 0 2px 6px rgba(0, 0, 0, 0.15);
transition: transform 0.25s ease, box-shadow 0.25s ease;
}

.ukabu:hover {
transform: translateY(-4px);
box-shadow: 0 10px 20px rgba(0, 0, 0, 0.2);
}

  • 枠線が塗られる

    border+background

    詳しくはこちら→
     .cta-white {
color: #256AFF;
background-color: #fff;
border: 2px solid #256AFF;
transition: background-color 0.3s ease, color 0.3s ease;
}

.cta-white:hover {
background-color: #256AFF;
color: #fff;
}

  • 矢印が進む

    アイコンだけ動かす

    詳しくはこちら→
    .yajirusi .icon {
display: inline-block;
transition: transform 0.25s ease;
}

.yajirusi:hover .icon {
transform: translateX(6px);
}

  • 光が走る

    ::after+translateX

    詳しくはこちら→
    .hikaru {
position: relative;
display: inline-block;
overflow: hidden;
}

.hikaru::after {
content: "";
position: absolute;
top: -50%;
left: 0;
width: 30%;
height: 200%;
background: linear-gradient(90deg,
                                transparent,
                                rgba(255, 255, 255, 0.7),
                                transparent);
transform: translateX(-150%) rotate(20deg);
 transition: transform 0.4s ease;
}
                    
.hikaru:hover::after {
transform: translateX(400%) rotate(20deg);
transition: transform 0.5s ease
}

（２）テキストリンクの下線

text-decorationではなく疑似要素で線を引くと、伸び方をコントロールできます。

3つのリンクにマウスを乗せてみよう。

  • 左から伸びる

    マウスを乗せる 
      
*/「マウスを乗せる」にlinkとlink-leftのクラス名をつける*/

.link{
    position: relative;
}

.link::after{
    content: "";
    position: absolute;
    left: 0;
    bottom: -6px;
    width: 100%;
    height: 2px;
    background-color: #FFC72C;
    transform: scaleX(0);
    transition: transform 0.3s ease;
}

/* 左から伸びる */
.link-left::after{
    transform-origin: left;
}

.link:hover::after{
    transform: scaleX(1);
 }

  • 中央から伸びる

    マウスを乗せる 
      
 */「マウスを乗せる」にlinkとlink-centerのクラス名をつける*/

.link{
    position: relative;
}

.link::after{
    content: "";
    position: absolute;
    left: 0;
    bottom: -6px;
    width: 100%;
    height: 2px;
    background-color: #FFC72C;
    transform: scaleX(0);
    transition: transform 0.3s ease;
}

/* 中央から伸びる */
.link-center::after{
    transform-origin: center;
}

.link:hover::after{
    transform: scaleX(1);
 }

  • 線が通り抜ける

    マウスを乗せる 
      
 */「マウスを乗せる」にlinkとlink-throughのクラス名をつける*/

 .link{
    position: relative;
}

.link::after{
    content: "";
    position: absolute;
    left: 0;
    bottom: -6px;
    width: 100%;
    height: 2px;
    background-color: #FFC72C;
    transform: scaleX(0);
    transition: transform 0.3s ease;
}

/* 線が通り抜ける */
.link-through::after{
transform-origin: right;
}

.link-through:hover::after{
    transform-origin: left;
    transform: scaleX(1);
}

（３）カードのホバー（画像のズーム+オーバーレイ）

親要素の :hover をきっかけに、中の複数の要素をまとめて動かすパターンです。 時間差（delay）をつけると上質に見えます。

3つのカードにマウスを乗せてみよう。

  • 画像ズーム

    画像だけを拡大し、枠からはみ出さないようoverflow: hiddenで切り取る

      
 */画像をimg-zoomで囲む*/
.img-zoom {
    overflow: hidden;
}

.hover-card .img-zoom img {
    transition: transform 0.3s ease;
}

.hover-card:hover .img-zoom img {
    transform: scale(1.12);
}
*/タイトルの色が変わる設定*/
.card-title {
    transition: color 0.3s ease;
}

.hover-card:hover .card-title {
    color: var(--main-color);
}
*/imgをcard-imgで囲む*/
.card-img {
    position: relative;
    overflow: hidden;
}

.card-img img {
    display: block;
}

.card-img::after {
    content: "VIEW MORE";
    position: absolute;
    inset: 0;
    background-color: rgba(255, 0, 0, 0.5);
    display: flex;
    justify-content: center;
    align-items: center;
    color: #fff;
    font-weight: bold;
    opacity: 0;
    transition: opacity 0.3s ease;
}

.hover-card:hover .card-img::after {
    opacity: 1;
}

  • カード全体が浮く

    カード自体を持ち上げ、影を強くすることでクリックできる印象を与える

      
 */カード全体にuku-cardというクラス名をつける*/
.uku-card {
    transition: transform 0.25s ease, box-shadow 0.25s ease;
}

.uku-card:hover {
    transform: translateY(-4px);
    box-shadow: 0 10px 20px rgba(0, 0, 0, 0.2);
}
*/タイトルの色が変わる設定*/
.card-title {
    transition: color 0.3s ease;
}

.hover-card:hover .card-title {
    color: var(--main-color);
}

*/imgをcard-imgで囲む*/
.card-img {
    position: relative;
    overflow: hidden;
}

.card-img img {
    display: block;
}

.card-img::after {
    content: "VIEW MORE";
    position: absolute;
    inset: 0;
    background-color: rgba(255, 0, 0, 0.5);
    display: flex;
    justify-content: center;
    align-items: center;
    color: #fff;
    font-weight: bold;
    opacity: 0;
    transition: opacity 0.3s ease;
}

.hover-card:hover .card-img::after {
    opacity: 1;
}

  • 色が抜ける

    filter: graytscale()を使うと、モノクロ⇄カラーの切り替えも滑らかになる。

      
*/画像にimg-grayとクラス名をつける*/
.img-gray {
    transition: filter 0.3s ease;
}
*/カード全体=gray-card*/
.gray-card:hover .img-gray {
    filter: grayscale(100%);
}
*/gray-overlayでimgを囲む*/
.gray-overlay {
    position: relative;
}

.gray-overlay::after {
    content: "VIEW MORE";
    position: absolute;
    inset: 0;

    display: flex;
    justify-content: center;
    align-items: center;
    color: #fff;
    text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.4);
    font-weight: bold;
    opacity: 0;
    transition: opacity 0.3s ease;
}

.gray-card:hover .gray-overlay::after {
    opacity: 1;
}

（4）グローバルナビ＆ドロップダウン

メニューの開閉は opacity ＋ visibility ＋ transform の3点セットが定番です。 子項目に transition-delay をずらして与えると、順番に現れます。

「ITEM」にマウスを乗せてみよう。

  • TOP
  • ABOUT
  • ITEM
    • アウター
    • トップス
    • パンツ
    • バック
    • シューズ
  • ACCESS
  
/* ITEMにドロップダウン専用のクラス名をつける */
.has-dropdown {
    position: relative;
}

/* ドロップダウン本体 */
.dropdown {
    position: absolute;
    top: 100%;
    left: 0;
    width: 150px;
    background-color: #fff;
    z-index: 10;
    box-shadow: 2px 2px 10px rgba(0, 0, 0, 0.3);

    opacity: 0;
    visibility: hidden;
    transform: translateY(-10px);

    transition:
        opacity 0.3s ease,
        visibility 0.3s ease,
        transform 0.3s ease;
}

/* ITEMをホバーした時、ドロップダウンを表示 */
.has-dropdown:hover .dropdown {
    opacity: 1;
    visibility: visible;
    transform: translateY(0);
}

/* ドロップダウン内のリスト */
.dropdown li {
    opacity: 0;
    transform: translateY(-5px);
    transition:
        opacity 0.3s ease,
        transform 0.3s ease;
}

/* ITEMをホバーした時、リストを表示 */
.has-dropdown:hover .dropdown li {
    opacity: 1;
    transform: translateY(0);
}

/* リストを時間差で表示 */
.dropdown li:nth-child(1) {
    transition-delay: 0.05s;
}

.dropdown li:nth-child(2) {
    transition-delay: 0.1s;
}

.dropdown li:nth-child(3) {
    transition-delay: 0.15s;
}

.dropdown li:nth-child(4) {
    transition-delay: 0.2s;
}

.dropdown li:nth-child(5) {
    transition-delay: 0.25s;
}

（6）トグルスイッチ

チェックボックスを隠し、:checked をきっかけに丸を移動させます。 JavaScript は不要です。

スイッチをクリックしてみよう。

  
/* トグルスイッチ */
/*-----html-----*/
<label class="toggle">
  <input type="checkbox">
  <span class="toggle-slider"></span>
</label>
/*-----html-----*/

.toggle{
    position: relative;
    display: inline-block;
    width: 60px;
    height: 32px;
}

.toggle input{
    opacity: 0;
    width: 0;
    height: 0;
}

.toggle-slider{
    position: absolute;
    inset: 0;
    background: #ccc;
    border-radius: 999px;
    cursor: pointer;
    transition: 0.3s;
}

/* 丸い部分 */
.toggle-slider::before{
    content: "";
    position: absolute;
    width: 24px;
    height: 24px;
    left: 4px;
    top: 4px;
    background-color: var(--main-color);
    border-radius: 50%;
    transition: 0.3s;
}

/* ONになったとき */
.toggle input:checked + .toggle-slider{
background-color: var(--sub-color);
}

/* ONになっとき、丸を右へ */
.toggle input:checked + .toggle-slider::before{
    transform: translateX(28px);
}

（7）アコーディオン

height: auto はアニメーションできませんが、 Grid の grid-template-rows: 0fr → 1fr を使うと、 中身の高さがいくつでもなめらかに開閉できます。

質問をクリックして開いてください。

今日は57日目です。

<div class="accordion">
    <input type="checkbox" id="acc01" class="acc-input">
    <label for="acc01" class="acc-title">
        毎日投稿何日目ですか？
    </label>

    <div class="acc-body">
        <div class="acc-inner">
            <p>
                今日は57日目です。
            </p>
        </div>
    </div>
</div>
/*-----html-----*/

.accordion {
    border: 1px solid #999;
    border-radius: 16px;
}

.acc-input {
    display: none;
}

.acc-title {
    position: relative;
    font-weight: bold;
    display: block;
    padding: 20px;
    cursor: pointer;
}

.acc-title::after {
    content: "+";
    position: absolute;
    right: 20px;
    top: 50%;
    transform: translateY(-50%);
    font-size: 20px;
    transition: transform 0.3s ease;

    transform: translateY(-50%) rotate(45deg);

animationとは？

時間の流れに沿って、要素を自動的に動かす。

（1）ローディング表現 4種

「処理中である」ことを伝えるパーツです。ずっと動き続ける＝ animation の代表格です。

  • スピナー

    rotate + border

      
.spinner {
    width: 40px;
    height: 40px;
    border: 4px solid #ccc;
    border-top-color: var(--main-color);
    border-radius: 50%;

    animation: spin 1s linear infinite;
}

@keyframes spin {
    to {
        transform: rotate(360deg)
    }
}

  • 3点ドット

    delay をずらす

      
.dots {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 8px;
}

.dots span {
    width: 10px;
    height: 10px;
    background-color: var(--main-color);
    border-radius: 50%;

    animation: dot 1s ease-in-out infinite;
}

.dots span:nth-child(2) {
    animation-delay: 0.15s;
}

.dots span:nth-child(3) {
    animation-delay: 0.3s;
}

@keyframes dot {

    0%,
    100% {
        transform: translateY(0);
    }

    50% {
        transform: translateY(-8px);
    }
}

  • バー

    overflow + translateX

      
.bar {
    position: relative;
    width: 160px;
    height: 6px;
    background-color: #ccc;
    border-radius: 3px;
    overflow: hidden;
}

.bar::before {
    content: "";
    position: absolute;
    top: 0;
    left: 0;
    width: 40%;
    height: 100%;
    background-color: var(--main-color);
    border-radius: 3px;

    animation: slide 1.5s ease-in-out infinite;
}

@keyframes slide {
    0% {
        transform: translateX(-100%);
    }

    100% {
        transform: translateX(250%);
    }
}

  • 波紋（パルス）

    scale + opacity

      
.pulse {
    position: relative;
    width: 20px;
    height: 20px;
    background-color: var(--main-color);
    border-radius: 50%;
}

.pulse::before {
    content: "";
    position: absolute;
    inset: 0;
    background-color: var(--main-color);
    border-radius: 50%;

    animation: pulse 1.5s ease-out infinite;
}

@keyframes pulse {
    0% {
        transform: scale(1);
        opacity: 0.6;
    }

    100% {
        transform: scale(3);
        opacity: 0;
    }
}
