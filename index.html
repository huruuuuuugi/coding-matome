TRANSITIONとは？

CSSの状態が変化するとき、その変化をなめらかにする。

（1）ボタン

ボタンにマウスを乗せて、実際に動きを体験しよう。

  • 色が変わる

    background-color

    詳しくはこちら→
    .iro {
    transition: background-color 0.25s ease;
}

.iro:hover {
    background-color: #FFC72C;
}

  • 背景が伸びる

    ::before + scaleX

    詳しくはこちら→
    .nobiru {
    position: relative;
    overflow: hidden;
    /* はみ出した背景を隠す */
    z-index: 0;
}

.nobiru::before {
    content: "";
    position: absolute;
    inset: 0;
    /* top/right/bottom/left: 0 のまとめ書き */
    z-index: -1;
    background-color: #FFC72C;
    transform: scaleX(0);
    /* 横幅0の状態からスタート */
    transform-origin: left;
    /* 左端を軸に伸ばす */
    transition: transform 0.3s ease;
}

.nobiru:hover::before {
    transform: scaleX(1);
}

  • 浮かび上がる

    translateY + box-shadow

    詳しくはこちら→
    .ukabu {
    box-shadow: 0 2px 6px rgba(0, 0, 0, 0.15);
    transition: transform 0.25s ease, box-shadow 0.25s ease;
}

.ukabu:hover {
    transform: translateY(-4px);
    box-shadow: 0 10px 20px rgba(0, 0, 0, 0.2);
}

  • 枠線が塗られる

    border + background

    詳しくはこちら→
    .cta-white {
    color: #256AFF;
    background-color: #fff;
    border: 2px solid #256AFF;
    transition: background-color 0.3s ease, color 0.3s ease;
}

.cta-white:hover {
    background-color: #256AFF;
    color: #fff;
}

  • 矢印が進む

    アイコンだけ動かす

    詳しくはこちら→
    .yajirusi .icon {
    display: inline-block;
    transition: transform 0.25s ease;
}

.yajirusi:hover .icon {
    transform: translateX(6px);
}

  • 光が走る

    ::after + translateX

    詳しくはこちら→
    .hikaru {
    position: relative;
    display: inline-block;
    overflow: hidden;
}

.hikaru::after {
    content: "";
    position: absolute;
    top: -50%;
    left: 0;
    width: 30%;
    height: 200%;
    background: linear-gradient(90deg,
            transparent,
            rgba(255, 255, 255, 0.7),
            transparent);
    transform: translateX(-150%) rotate(20deg);
    transition: transform 0.4s ease;
}

.hikaru:hover::after {
    transform: translateX(400%) rotate(20deg);
    transition: transform 0.5s ease;
}

（2）テキストリンクの下線

text-decorationではなく疑似要素で線を引くと、伸び方をコントロールできます。

3つのリンクにマウスを乗せてみよう。

  • 左から伸びる

（3）カードのホバー（画像のズーム＋オーバーレイ）

親要素の :hover をきっかけに、中の複数の要素をまとめて動かすパターンです。時間差（delay）をつけると上質に見えます。

3つのカードにマウスを乗せてみよう。

  • 画像ズーム

    画像だけを拡大し、枠からはみ出さないよう overflow: hidden で切り取る

    /* 画像をimg-zoomで囲む */
.img-zoom {
    overflow: hidden;
}

.hover-card .img-zoom img {
    transition: transform 0.3s ease;
}

.hover-card:hover .img-zoom img {
    transform: scale(1.12);
}

/* タイトルの色が変わる設定 */
.card-title {
    transition: color 0.3s ease;
}

.hover-card:hover .card-title {
    color: var(--main-color);
}

/* imgをcard-imgで囲む */
.card-img {
    position: relative;
    overflow: hidden;
}

.card-img img {
    display: block;
}

.card-img::after {
    content: "VIEW MORE";
    position: absolute;
    inset: 0;
    background-color: rgba(255, 0, 0, 0.5);
    display: flex;
    justify-content: center;
    align-items: center;
    color: #fff;
    font-weight: bold;
    opacity: 0;
    transition: opacity 0.3s ease;
}

.hover-card:hover .card-img::after {
    opacity: 1;
}

    filter: grayscale() を使うと、モノクロ⇄カラーの切り替えも滑らかになる。

「ITEM」にマウスを乗せてみよう。

animationとは？

時間の流れに沿って、要素を自動的に動かす。

（1）ローディング表現 4種

（3）登場演出（フェードイン＋時間差）

ページを開いたときにふわっと現れる演出です。animation-delay をずらすと、順番に出てくる「ずらし（stagger）」になります。

@keyframes fadeInUp {
    from {
        opacity: 0;
        transform: translateY(80px) scale(0.85);
        filter: blur(8px);
    }

    to {
        opacity: 1;
        transform: translateY(0) scale(1);
        filter: blur(0);
    }
}

.image-list {
    display: flex;
    gap: 16px;
}

.image-list img {
    flex: 1;
    min-width: 0;
    height: auto;
}

/* ---------------------------------------------
   スクロール量に合わせて表示（JSなし）
   animation-timeline: view() で、アニメーションの進み具合を
   「時間」ではなく「要素が画面のどこにいるか」に連動させる
   → 速くスクロールすれば速く、止めれば途中で止まる
   → 上に戻せば逆再生されるので、スクロールのたびに登場する
   ※ スクロール連動では animation-delay（秒）は効かないので、
     時間差は animation-range の開始・終了位置をずらして作る
--------------------------------------------- */
@supports (animation-timeline: view()) {
    .fadein-item {
        animation: fadeInUp linear both;
        animation-timeline: view();
    }

    /* 時間差（stagger）：後の画像ほど遅い位置で始まる
       終わりを entry 100%（画像が画面に入りきった位置）までに収めると、
       ページ最下部の要素でも最後まで表示される */
    .image-list .fadein-item:nth-child(1) {
        animation-range: entry 0% entry 60%;
    }

    .image-list .fadein-item:nth-child(2) {
        animation-range: entry 20% entry 80%;
    }

    .image-list .fadein-item:nth-child(3) {
        animation-range: entry 40% entry 100%;
    }
}

@media (prefers-reduced-motion: reduce) {
    .fadein-item {
        opacity: 1;
        animation: none !important;
    }
}

@media (max-width: 600px) {
    .image-list {
        flex-direction: column;
        align-items: center;
    }

    .image-list img {
        width: auto;
        max-width: 280px;
    }
}

    animation-play-state: paused;
}

（6）画面に入ったらふわっと表示

animation-timeline: view() は、「その要素が画面に入ってから出ていくまで」を時間の代わりに使います。Webサイトで最もよく求められる演出が、CSSだけで実現できます。

ゆっくりスクロールしてください。カードが順に現れます。

下から現れる

スクロールして画面に入ってきたタイミングで、透明度と位置が変化します。

拡大しながら現れる

animation-range を指定すると、「どのくらい見えたら再生を始めるか」を調整できます。

横から滑り込む

スクロールを戻すと、アニメーションも巻き戻ります。時間ではなく位置に連動しているためです。

.reveal-flex {
    display: flex;
    flex-direction: column;
    gap: 24px;
}

.text-accent {
    color: var(--main-color);
    font-weight: bold;
}

.reveal-up,
.reveal-scale,
.reveal-slide {
    display: block;
    border: 2px solid #000;
    padding: 8px;
    animation-timing-function: linear;
    animation-fill-mode: both;
    animation-timeline: view();
    animation-range: entry 10% cover 35%;
}

/* ① 下から現れる */
@keyframes reveal-up {
    from {
        opacity: 0;
        transform: translateY(40px);
    }

    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.reveal-up {
    animation-name: reveal-up;
}

/* ② 拡大しながら現れる */
@keyframes reveal-scale {
    from {
        opacity: 0;
        transform: scale(0.8);
    }

    to {
        opacity: 1;
        transform: scale(1);
    }
}

.reveal-scale {
    animation-name: reveal-scale;
}

/* ③ 横から滑り込む */
@keyframes reveal-slide {
    from {
        opacity: 0;
        transform: translateX(-60px);
    }

    to {
        opacity: 1;
        transform: translateX(0);
    }
}

.reveal-slide {
    animation-name: reveal-slide;
}

（7）回転する光の枠線（@property）

グラデーションの角度は、そのままではアニメーションできません。@property で「これは角度である」とブラウザに教えると、CSS変数そのものをなめらかに変化させられるようになります。

Always Rotate

常に回転する光の枠線。料金プランなどで使えそう。

Hover to Rotate

ホバーすると回転する光の枠線

@property --angle {
    syntax: "<angle>";
    initial-value: 0deg;
    inherits: false;
}

@keyframes rotate-angle {
    to {
        --angle: 360deg;
    }
}
